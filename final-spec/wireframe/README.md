# Clickable wireframe

Open index.html directly in a modern browser. No server/build/CDN/fonts/API key/network required. Copy whole final-spec folder to preserve the PDF link.

Throwaway workflow prototype, not production React/Vite or model demonstration. Complete eight-customer navigation cohort: six eligible, two ineligible, ceil(.05*6)=one selected. Evaluation numbers illustrate a separate multi-world report. Amended for version 1.1: return-rate rule rank beside the model rank, linked-claim style evidence, a sixth style state and report-only reference rows.

## Walkthrough

1. Overview -> compare the two lists (selected by model only / by return-rate rule only) -> Customer queue -> Show all -> search C-005.
2. Open case -> evidence/timeline/relationships -> linked style/SKU.
3. Notes -> reviewer/disposition/note -> append -> navigate away/back.
4. Datasets & runs -> simulate another run -> same customer notes retain originating run.
5. Style queue -> state filter -> detail -> linked customer.
6. Evaluation -> candidate gates and report-only references -> reveal illustrative truth (only here).
7. No candidate passed or Final test failed -> banner and baseline ranking change.
8. Try Loading/Empty/Job failed/No scoring bundle and Reset.

File-name preview never validates CSV contents/hashes. Jobs simulated; notes memory-only until reload/reset. Browser back/forward uses hash routes. Production implements React/Vite against contracts/openapi.yaml. Visual acceptance is not asserted merely by producing a prototype.
