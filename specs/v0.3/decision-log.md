# v0.3 decision log

Purpose: record every question raised in the v0.3 review, the answer given, and how to verify later that the decision was carried into specs and code. This file is the freeze record (D-006).

Conventions
- **D-xxx** is a decision the user gave in this session. The answer is recorded as given; interpretation is marked separately.
- **Q-xxx** is an open question. "Proposed" is the reviewer's recommended default. It is **not** a decision until the user marks it ACCEPTED or CHANGED.
- **V02-DEF-nn** is a v0.2 engineering default awaiting user sign-off.
- **R-nn** is a risk to track; it needs no decision.
- Status values: `DECIDED` (answered, not yet signed; none remain after the 2026-09-25 sign-off), `ACCEPTED` / `CHANGED` (signed by the user), `OPEN`, `DEFERRED` (user asked to discuss later).
- The "Verify by" column describes the evidence that will prove the decision was implemented. A decision is not verified until that evidence exists.
