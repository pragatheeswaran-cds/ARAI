Two panels that sit below the evidence, never above it

Wardrobing indicator · possible

Two occasion-wear items returned in the last quarter of their window. Two quality complaints on styles other buyers do not complain about.

The limitation, printed on the panel: it cannot establish that an item was worn, and it is independent of the model score.

Investigation memo · draft

Drafted after the run for each selected customer, when an API key is configured: summary, key evidence, alternative explanations, recommended action.

Every draft is checked against the case’s own numbers before it is stored. A draft that fails twice is stored as unavailable, with the reason.

Without a key the panel says “Memo unavailable: no API key” and nothing else. That is the design, not an error.
