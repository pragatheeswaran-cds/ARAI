How a new month gets in

1

Register a snapshot

Eight files: a manifest and seven tables. Validation against the data contract runs on upload; a snapshot that fails is rejected whole, and the page lists every broken rule.

2

Score with the active bundle

The stepper shows the stages as the worker reports them: validate, features, eligibility, scoring, evidence, publish. 10,000 customers took 13 seconds. A run can be cancelled while it is in progress.

3

Scoring readiness

Names the active bundle, the baseline it falls back to, and the worker’s last heartbeat. When no model passes the gate, the return-rate baseline is served and the banner says why.

Registering W5401 again answers with the existing dataset; a new run starts with a fresh idempotency key, and previous runs and notes stay.
