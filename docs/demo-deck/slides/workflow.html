Refusal

The reviewer who opened the case writes a note and presses Approve. The server answers, and the page shows its words:

“You opened this case. A different reviewer must approve or reject it.”

Approval

A second reviewer types their name, writes a note and presses Approve. The status tile turns to Approved with both names and times.

Notes are append only and each one says which run it was written on.

Also on the page: “If the threshold moved”, a slider that shows how many customers the queue would hold at any score. It changes nothing on the server.
